# Línea base del guardián «verificarCamuflajeDex».
#
# El guardián juzga TODAS las cadenas del artefacto release contra los 49 términos
# vedados, sin filtro previo de atribución. El alcance no es solo el DEX: son las 197
# entradas del APK que este build puede escribir —`resources.arsc`, el manifiesto
# binario, `res/**`, `META-INF/**`, `assets/**` sin las fuentes vendidas de PdfBox, y
# los dos archivos de raíz que genera el propio build—, de ahí la última sección. Eso es lo correcto —una cadena propia
# que no lleve la ruta del paquete sería invisible para cualquier heurística— pero
# obliga a absorber aquí, una por una y con su causa escrita, el ruido de las
# librerías: javax.crypto usa «secret», EXIF usa «ISOSpeed», gRPC usa «panic».
#
# Dos reglas:
#   1. El guardián falla ante CUALQUIER cadena que no esté en esta lista. Su
#      trabajo es impedir que el problema crezca, no fingir que no existe.
#   2. Para retirar una línea de aquí hay que arreglar la causa, no ampliar la
#      lista. Las de Aurora llevan pendiente; las de librería, no (no hay nada
#      que arreglar en código ajeno).
#
# Coincidencia exacta, para que una excepción no tape de rebote una cadena nueva.
# El DEX guarda cada cadena precedida de su longitud en MUTF-8, y ese byte a veces
# resulta imprimible y se pega al principio («?Lcom/...», «Dio.perfmark...»). El
# guardián lo detecta por regla —el primer carácter es prefijo de longitud si su
# valor coincide con la longitud en bytes del resto— y lo descarta antes de
# comparar, así que aquí las cadenas se escriben LIMPIAS. Antes se escribían con
# el artefacto pegado y la excepción habría dejado de aplicar en silencio en
# cuanto la cadena cambiara de longitud (hallazgo M-6 de la auditoría de la rama).
#
# Precisión sobre esa regla: MUTF-8 codifica el número de unidades UTF-16, y la
# comprobación compara contra la longitud en bytes UTF-8. Para cadenas con tildes
# los dos números difieren y el prefijo NO se quita. Yerra hacia el falso positivo
# —la cadena se reporta en vez de silenciarse—, que es el lado seguro, pero quien
# vea una excepción que no aplica a una cadena acentuada ya sabe por qué.
